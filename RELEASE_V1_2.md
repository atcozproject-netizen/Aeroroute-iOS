# Aeroroute V1.2 – One tap operations
- Airport tap: simple terminal capacity and upgrade action; directly below that is a list of connected routes. No clutter from suggested unrelated destinations.
- One route: single aircraft selection action; multiple routes: select the corresponding route, then see all available aircraft.
- Route-line tap on world map: geometric 17px tap corridor opens aircraft model picker directly. Closely positioned airport markers retain priority. Panning and pinching never select a line.
- Aircraft selector lists all actual models, showing installed aircraft, range, seat capacity and real buy/trade-in price (not only levels greater than current). Invalid or unaffordable aircraft are disabled.
- A secondary button reveals airfare and detailed route finance on demand.
- Airport upgrades have the same costs in UI as GameState; existing saves and terminal costs unchanged.
- Current route remains subtly highlighted on the map behind the model selector.
